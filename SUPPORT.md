# Support

Keyword Pro is a maintainer-led, local-first open-source application. Support
is best-effort and does not include an uptime, response-time, or paid-provider
service guarantee.

## Before asking for help

1. Follow the setup steps in the [README](README.md) from a clean checkout.
2. Confirm that Node.js and pnpm match `.nvmrc` and `package.json`.
3. Run `pnpm --ignore-workspace run ci`.
4. Search existing issues for the same symptom.

Do not paste `.env` contents, API credentials, encryption keys, database dumps,
full provider responses, personal data, or private research exports into an
issue or screenshot.

## Where to ask

- Use the [bug report form](https://github.com/AgriciDaniel/keywordpro/issues/new?template=bug_report.yml)
  for a reproducible application defect.
- Use the [feature request form](https://github.com/AgriciDaniel/keywordpro/issues/new?template=feature_request.yml)
  for a focused product proposal.
- Join the [AI Marketing Hub free community](https://www.skool.com/ai-marketing-hub)
  or [AI Marketing Hub Pro](https://www.skool.com/ai-marketing-hub-pro) for
  broader keyword-research discussion.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never report
  a security issue publicly.

DataForSEO account access, billing, quotas, endpoint availability, and provider
response disputes are controlled by DataForSEO. Keyword Pro contributors can
help diagnose application behavior, but cannot change a provider account or
guarantee provider data.

Live troubleshooting calls may spend money from the connected DataForSEO
account. No maintainer or contributor should initiate one without the account
owner's explicit approval.
