# Keyword Pro v1.0.0

Status: release-candidate draft for `v1.0.0-rc.1`. Do not publish these notes
as a final release until the owner gates below are closed on the exact tagged
commit.

Keyword Pro v1.0.0 will be the first public release of the local-first keyword
research console.

## Highlights

- Run a guided, market-aware keyword report covering demand, CPC, difficulty,
  intent, trends, competitors, and related queries.
- Choose from 94 markets and the complete 46-language guided-report catalog
  while preventing invalid country-language pairs.
- Explore 332 keyword endpoints in Advanced mode.
- Compare opportunity, difficulty, historical demand, audience, regional, and
  discovery views.
- Save completed reports locally and reopen them without another paid call.
- Export keyword results as PDF, CSV, and JSON.
- Bring your own DataForSEO credentials through local environment settings or
  the Connections screen.
- Create or upgrade the local database through an idempotent, transactional
  migration that preserves private-preview saved reports and encrypted values.
- Inventory retained private-preview data without exposing identifiers or
  encrypted values, then optionally export a private compatibility snapshot.
- Use, modify, and distribute the project under the Apache License 2.0.
- Review eight actual application screenshots backed only by the deterministic
  synthetic demo report.

## Privacy and supported use

Keyword Pro is designed for one local user. Credentials remain server-side,
saved credentials are encrypted at rest, and the application binds to loopback
by default.

This is not a hardened hosted or multi-user service. Do not expose it directly
to a LAN or the internet without authentication, trusted secret management,
shared rate limiting, privacy-safe observability, and a deployment-specific
threat review.

Live research spends money from the connected provider account. Keyword Pro
shows an estimate before a run. The estimate, source count, results, and panels
vary by query, market, language, account access, and provider coverage.

## Release-candidate verification

The release candidate has been exercised through a frozen clean install, two
database migrations, local-user seed, counts-only legacy inventory, offline
verification, a production build, dependency audit, Compose validation, and a
loopback production smoke test. The deterministic fixture and screenshot gates
pass without a provider call.

Visible-browser acceptance covers the research workspace, synthetic 27-keyword
report, 19-source receipt, desktop and 390-pixel layouts, chart resizing, the
94-market and 46-language targeting catalog, valid-pair repair, select-chevron
spacing, Connections community links, and the production console. The browser
run used synthetic data and spent nothing.

A one-commit clean-history projection has no remote and exactly matches the
reviewed source tree and source archive. The projection scan rejects runtime
state, local absolute paths, non-placeholder email addresses, common credential
markers, and Git metadata in the archive.
